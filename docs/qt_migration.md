# CameraView Qt 迁移说明

## 迁移结果

默认桌面应用现已使用 Qt 6 Widgets。原来的 Win32 窗口、消息循环、控件布局和 GDI 视口不再进入默认 `CameraView` 目标；MUCam SDK 动态加载、相机驱动以及既有领域算法继续复用。

Qt 前端位于 `src/qt/`：

- `CameraMainWindow`：菜单、工具栏、可停靠功能面板和业务状态管理。
- `CameraWorker`：在独立 Qt 线程中枚举设备、打开相机和采集帧，避免阻塞界面线程。
- `ImageCanvas`：Qt 绘制的图像视口，支持适合窗口、光标中心缩放、平移和测量交互。
- `HistogramWidget`：Qt 绘制的多通道直方图与统计信息。
- `ai/YoloWorkspaceWidget`：YOLO 检测、分类、分割、训练和模型管理工作台。
- `ai/YoloProcessController`：异步 Python 后端进程与 JSON 事件协议。
- `ai/YoloModelRegistry`：用户级模型权重和元数据持久化。

默认 Qt 版已经接入：

- MUCam 设备刷新、打开/停止、曝光、自动曝光、增益和白平衡；
- 离线图像打开、拖放、翻转/旋转、PNG/JPEG/TIFF/BMP 导出；
- 亮度、对比度、伽马、窗位/窗宽、伪彩和多通道直方图；
- 点坐标、长度、折线长度、角度、矩形、多边形、圆、椭圆、两点标定、自动寻边、结果高亮/定位、重命名和 CSV 导出；
- 测量工具使用按功能生成的高 DPI 矢量图标按钮，采用三列网格布局并与画布工具状态同步；
- 独立测量工具栏完整覆盖标定、全部测量类型、智能计数、自动寻边和结果管理操作；
- 非破坏性图像处理链支持灰度、反相、自动对比度、直方图均衡、平滑、降噪、锐化、边缘检测和二值化，并支持逐步撤销；
- 基于用户矩形框选样本的智能目标计数，支持任意形状目标、多尺度相似匹配、重复抑制、后台进度/取消和结果定位；
- 图像 3D 高度图，支持亮度/R/G/B 高度通道、旋转、平移、缩放、网格精度/高度倍率/着色切换和 PNG 导出；
- 交互式剖线测量，支持亮度与 RGB 通道曲线、标定距离、统计量、CSV 数据及曲线图导出；
- 荧光通道采集、可见性/黑白电平设置及融合预览；
- 当前帧或批量文件加入多帧拼接与 EDF 景深扩展，耗时任务通过 QtConcurrent 后台执行；
- CameraView 项目保存与恢复、现场诊断报告导出；
- Qt 与 MUCam 运行时自动部署到可执行文件目录。
- YOLO 模型导入/管理、检测/分类/实例分割、训练进度与日志、训练产物自动入库和 ONNX 导出。

## 构建

建议使用仓库自带的 PowerShell 构建入口，它会查找 Qt、CMake、Ninja 和匹配 Qt ABI 的 MinGW/MSVCRT 编译器：

```powershell
.\tools\build_qt.ps1
```

指定 Qt 安装目录：

```powershell
.\tools\build_qt.ps1 -QtRoot C:\Qt6\6.9.0\mingw_64
```

可选参数：

- `-WithOpenCV`：启用 OpenCV 拼接后端；未安装时仍使用内置后端。
- `-OpenCVRoot <目录>`：显式指定包含 `OpenCVConfig.cmake` 的 OpenCV 根目录。未指定时会依次检查当前用户的 `OpenCV_DIR`、`OpenCV_ROOT` 和 `%USERPROFILE%\\tools\\opencv_mingw`，因此不需要管理员权限或系统级安装。

## Qt 图像拼接工作流

“处理 → 图像拼接”已接入完整的拼接后端：

1. 可从当前图像、多个文件或整个目录建立源图队列；队列支持查看、排序、删除和清空。
2. 支持网格/线性排列、网格行列数、预计重叠率、显微/自动/相位/ORB/SIFT 配准、平移/仿射/透视变换和线性羽化。
3. 打开相机后可启动实时拼接。软件会在后台判断移动量和重叠率，合格时自动采集，并在主画布更新低分辨率拼接预览；重叠不足时会给出移回提示。
4. 最终拼接在后台运行，显示进度并可取消。优先使用 OpenCV C++ 后端；未配置 OpenCV 时自动回退到内置算法。
5. 完成后会显示实际后端、配准关系数和输出尺寸，并可单独导出 PNG、TIFF 或 JPEG 结果。

推荐构建命令：

```powershell
.\tools\build_qt.ps1 -WithOpenCV
```

- `-SkipTests`：仅构建，不运行领域测试。

## 3D 高度图与剖线测量

- 打开图像后，通过“图像 → 3D 高度图…”或工具栏的“3D 高度图”打开三维视图。左键拖动旋转，右键或中键拖动平移，滚轮缩放，双击复位视角。
- 三维高度可独立选择当前显示图像的亮度、红、绿、蓝通道，适合分别观察各通道的纹理、边缘和强度起伏；在没有深度标定数据时，它不表示真实物理高度。
- 3D 视图使用 Qt OpenGL 画布加速曲面绘制，同时缓存每个网格顶点的投影并使用四边形表面；高精度网格在拖动时自动降低交互细节，松开后立即恢复完整质量。设置区会显示实际 OpenGL 渲染器；显卡驱动不可用时由 Qt 软件 OpenGL 自动回退。
- 通过“图像 → 剖线测量”、快捷键 `P` 或测量面板的“剖线”按钮启动；在图像上依次选择两个端点后，会保留黄色定位线并打开强度曲线。
- 曲线窗口可切换亮度、红、绿、蓝通道，显示长度、样本数、最小值、最大值、平均值和标准差。完成两点标定后，横轴自动使用当前测量单位，否则使用像素。
- 剖线原始数据可导出为 UTF-8 CSV，当前曲线和 3D 视图可导出为 PNG。
- `-BuildDirectory <目录>`：指定构建目录。

构建完成后，`CameraView.exe`、Qt DLL、Qt 插件、MinGW 运行时以及 MUCam DLL 位于同一个构建目录，可直接启动。

## CMake 目标

- `CameraView`：默认 Qt 6 应用。
- `CameraViewDomainTests`：原有核心领域测试。
- `CameraViewYoloRegistryTests`：YOLO 模型库导入、元数据、活动模型和托管文件生命周期测试。

旧 Win32 源码继续保留在 `src/ui/` 与 `src/main.cpp`，用于迁移差异追踪，但不再作为产品构建目标。

## 平台边界

界面和图像交互已迁移到 Qt，但当前随仓库提供的 MUCam SDK 是 Windows DLL，因此真实相机采集仍限于 Windows。离线图像、测量和处理层保持与 Qt 界面解耦，后续可以为其他平台增加不同的 `ICameraDriver` 实现。
